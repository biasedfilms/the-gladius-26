# No AI Slop — The Gladius 26

The objective is not merely to make the page attractive. It must look as though a thoughtful designer created it specifically for this collective and this emblem.

## Reject these defaults

- Purple-to-blue gradients, generic gradient blobs, neon accents, and glassmorphism.
- A standard SaaS landing page with navbar, oversized gradient CTA, three feature cards, testimonial cards, and pricing table.
- Repeating the same rounded card for every story chapter.
- Default Inter/Roboto typography with no typographic point of view.
- Generic circuit-board backgrounds or random engineering stock illustrations.
- Unrelated medieval castles, weapons, helmets, or fantasy stock art.
- Excessive hairline borders, metadata labels, pills, and arbitrary icons.
- A sequence of identical fade-up animations on every element.
- Filler copy, fake Latin, fake statistics, invented historical details, and exaggerated claims.
- Decorative buttons and links that do nothing.

## Project-specific visual test

Every major visual decision should relate to at least one of these real anchors:

1. The Gladius emblem and its navy/blue, gold, and silver palette.
2. The generational link: The Gladiators 23 → The Gladius 26.
3. The five actual emblem elements and their supplied meanings.
4. The Faculty of Engineering and university context.

If a detail cannot be tied to the content, brand, hierarchy, or usability, question whether it belongs.

## Distinctiveness process

1. Write down the page's single communication goal.
2. Select a memorable composition rather than assembling generic components.
3. Use typography and the real emblem as the main visual assets.
4. Build only the motion that strengthens the story.
5. Inspect the page at real viewport sizes.
6. Conduct a critique: identify three weakest/most generic areas and improve them before handoff.

## Copy quality

- Do not use inflated phrases such as “redefining the future” unless the owner explicitly supplies that claim.
- Do not add generic mission/vision language.
- Do not invent student achievements or institutional praise.
- Prefer exact, concise, meaningful statements over filler.

## Acceptance test

Could this design be mistaken for a generic AI-generated university template after removing the logo? If yes, it is not distinctive enough. Improve the structure, type composition, editorial rhythm, or motion using the actual identity—not arbitrary decoration.

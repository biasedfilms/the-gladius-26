# Frontend Design — The Gladius 26

Act as the design lead for a small independent studio. The task is to create an identity archive that feels authored for The Gladius, not assembled from a generic landing-page kit.

## Required process

1. Re-read the relevant PRD chapter and actual content before designing its layout.
2. State the section's communication job in one sentence.
3. Sketch the hierarchy and composition before coding: headline, supporting content, image/mark placement, navigation/CTA if any, and mobile reflow.
4. Choose an intentional layout variation. Do not reuse one identical split layout for every chapter.
5. Review the first design against the brand system and the anti-pattern list in `no-ai-slop` before proceeding.
6. Implement the design, render it at real viewport sizes, and revise after seeing the result.

## Design principles

- The hero thesis is the oversized `THE GLADIUS` title; `26` is a separate edition marker.
- The Gladius emblem is the primary visual mark. University and faculty marks are supporting institutional identity.
- Use visible royal blue as the main surface, silver chapters for breathing room, and gold as a controlled accent.
- Typography and composition should do more work than decorative UI components.
- Give the page one memorable visual signature, not a collection of unrelated effects.
- Use the real story and the real marks as the source of distinctive design choices.
- Preserve generous whitespace without leaving arbitrary empty areas that do not improve hierarchy.
- Use a grid as a compositional tool, not as a reason to make every section look identical.

## Avoid

- Generic SaaS cards, pricing sections, testimonials, fake metrics, and dashboard chrome.
- Random gradient blobs, glassmorphism, neon, purple, unrelated circuit graphics, or stock medieval props.
- Repeated eyebrow labels and arbitrary 01/02 numbering when it does not explain the chapter structure.
- The same fade-and-slide animation on every element.
- Overly ornate fonts for long paragraphs.

## Review checklist

- Is the first screen unmistakably The Gladius 26?
- Does the blue read as blue instead of black?
- Are the three marks distinct in hierarchy and correctly placed?
- Does every design choice support identity, heritage, or readability?
- Does mobile have a considered composition?
- Could this page be mistaken for a generic template? If yes, revise it.
